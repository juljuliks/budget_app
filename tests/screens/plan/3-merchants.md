# План тестов · 3. Мерчанты · тесты экранов (Jest)

Обозначения, Дано / Шаги / Ожидается и где что проверяется — [tests/README.md](../../README.md).

### 3.1 Список (Настройки → «Мерчанты»)

**3.1.1 Пусто** — «Мерчанты появятся после первых покупок.».

**3.1.2 Разделы**
- Мерчанты покупок и оплат (не переводов) по категориям: «Без категории» первым, затем «Разные категории», затем категории в их порядке.
- Заголовок «🛒 Продукты · 5 мерчантов»; внутри частые выше.
- Мерчант, чья категория удалена, — в «Без категории».

**3.1.3 Активность**
- Покупки за 30 дней: «За последний месяц: 3 покупки на 45.20 ₾».
- Мерчант без покупок за 30 дней — в свёрнутом разделе «Давно не было покупок · N мерчантов» внизу с «Показать» / «Свернуть»;
  в строке категория и «5 покупок на 120 ₾ · 12 мая – 20 авг» (год, если не текущий).
- Несколько валют: «на 45 ₾ + 20 $».

**3.1.4 Поиск** — «Найти мерчанта», без регистра; при поиске давние мерчанты показаны в своих категориях; «Не найдено.» при пустом результате.

**3.1.5 Фильтр «Категория»** — «Без категории», «Разные категории», категории с числом мерчантов; несколько сразу.

### 3.2 Карточка мерчанта

**3.2.1 Открытие**
- Тап → имя, «N операций · X ₾» (покупки и оплаты минус неучтённые возвраты), «Показать операции ›», переключатель «Разные категории» («Каждая новая операция спрашивает категорию»), категория, «Сохранить» (неактивна), «Удалить мерчанта».

**3.2.2 Первая категория**
- Дано: мерчант без категории. Шаги: выбрать «Продукты» → «Сохранить».
- Ожидается: вопроса нет; тост «Категория «🛒 Продукты» назначена мерчанту «SPAR»»; правило создано; операции без категории и по правилу получили её.

**3.2.3 Смена категории с прошлыми операциями**
- Дано: у мерчанта «Продукты», 4 операции по правилу на 120 ₾.
- Шаги: «Сменить» → «Кафе» → «Сохранить».
- Ожидается:
  - лист «Категория «Кафе» для «SPAR»», «Какую категорию сделать для 4 прошлых операций на 120 ₾?»,
    «Новые операции будут получать «Кафе». Выбранные вручную категории не изменятся.»;
  - кнопки «Отмена», «Кафе», «Продукты».
- «Кафе» → прошлые операции по правилу стали «Кафе».
- «Продукты» → прошлые остались «Продукты», но стали `category_source=user` (больше не следуют за мерчантом); новые → «Кафе».
- Без операций по правилу → без вопроса.

**3.2.4 Убрать категорию**
- «Без категории» → «Без категории для «SPAR»», «Новые операции будут приходить без категории. …», кнопки «Без категории» / «Продукты».
- Тост «Новые операции «SPAR» будут приходить без категории»; правило удалено.

**3.2.5 Включить «Разные категории»**
- Шаги: переключатель → список «Категории мерчанта» («Какие обычно категории у «WOLT»?») заполнен категориями его операций → «Сохранить».
- Ожидается:
  - лист «Разные категории у «WOLT»: «Продукты», «Кафе»» и текст «Каждая новая операция «WOLT» будет спрашивать категорию — в уведомлении кнопками будут эти категории. Категория, выбранная для операции, добавится к ним. Категория мерчанта «Продукты» открепится, у прошлых операций она останется.»;
  - «Продолжить» → тост «WOLT»: разные категории»;
  - в базе: `mixed_merchants` есть, правило удалено, операции по правилу → `user`, `merchant_categories` = выбранные.
- «✕» на чипе убирает категорию из списка; «＋ Добавить категорию» → множественный выбор.

**3.2.6 Выключить «Разные категории» с выбором категории**
- Лист «Категория «X» для «WOLT»», «Новые операции мерчанта будут получать её автоматически. Разные категории выключатся.» → «Продолжить».

**3.2.7 Выключить без категории** — без вопроса; новые операции без категории.

**3.2.8 Показать операции** — «Операции» с поиском по имени мерчанта, «Назад» → «Мерчанты».

**3.2.9 Удалить мерчанта**
- «Удалить мерчанта» → «Удалить мерчанта «SPAR»?», «4 покупки останутся в операциях со своими категориями, но без мерчанта. Новые операции этого мерчанта не будут получать категорию автоматически. Новые SMS от него снова создадут мерчанта.».
- После удаления тост «Мерчант «SPAR» удалён»:
  - операции `merchant_key=NULL`, `raw_merchant=NULL`, категории на месте (`user`);
  - правило, `mixed_merchants` и `merchant_categories` мерчанта удалены.
- Новое SMS от SPAR → мерчант снова появился, без категории.

### 3.3 Мультивыбор мерчантов

**3.3.1** Долгое нажатие → «Выбрано: 1», «Отмена»; тап отмечает; снять последнего → выход.

**3.3.2 Категория нескольким**
- «Категория (N)» → категория → «Категория «X» для 3 мерчантов?», «Новые операции этих мерчантов будут получать её автоматически. Категория изменится у N операций на X ₾. Выбранные вручную категории не изменятся.» → «Сохранить».
- Тост «Категория «X» назначена: 3 мерчанта»; правила созданы, операции по правилу перенесены.

**3.3.3 Удалить нескольких**
- «Удалить (N)» → «Удалить мерчантов (3)?» → «Удалить (3)» → тост «Удалено мерчантов: 3».
- Один выбран → формулировки «мерчанта» в единственном числе.
