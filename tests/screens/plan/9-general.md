# План тестов · 9. Общее · тесты экранов (Jest)

Обозначения, Дано / Шаги / Ожидается и где что проверяется — [tests/README.md](../../README.md).

**9.2 Стартовые категории**
- Чистая установка: «Продукты», «Кафе и рестораны», «Транспорт», «Такси», «Дом и коммуналка», «Здоровье», «Подписки», «Покупки», «Развлечения», «Путешествия», «Переводы», «Другое»; системные «Пополнение счёта» и «Между своими картами».
- Раздел «Переводы».

**9.3 Обновление** — база прошлой версии (seed на старой схеме) → после запуска данные на месте, миграции применены.
**9.4 Стартовая вкладка** — запуск всегда на «Операциях».
**9.5 Меню ⋮** — в шапках обеих вкладок (в «Статистике» — после «Динамики трат» и глаза) ⋮ → шит из трёх строк:
«Категории» (разделы, эмодзи, вид в плане), «Мерчанты» (какая категория у какого магазина), «Настройки» (бюджет, банки,
приложение). Строка открывает страницу поверх вкладки, «Назад» — на ту вкладку, откуда открыли.
**9.5.1 Настройки** — страница (стрелка «назад» в шапке) с табами «Бюджет | Банки | Приложение» под заголовком;
открывается на «Бюджете», выбранный таб — до закрытия страницы. «Бюджет»: «Валюта», «🔒 Отложить сразу» (6.2.1),
«Уведомлять о лимитах».
«Банки»: «Банки», «Шаблоны сообщений» (страницы поверх, «Назад» — к ним), «Импорт SMS из телефона» (шит). «Приложение»:
«Блокировка» («Настроить» — шит), «Резервная копия» (шит), внизу «Версия 1.0.N» (в тестах — «Версия dev»).
«Категорий» и «Мерчантов» в них нет.
**9.7 Без сети** — статистика без курса показывает «Не учтено — нет курса…», приложение не падает.
**9.8 Ошибки сохранения** — при ошибке базы тосты «Не удалось сохранить» / «Не удалось удалить», данные не испорчены.

**9.10 Не загрузилось**
- **9.10.1** Статистика не прочиталась (ошибка базы) → «Не удалось загрузить» и «Повторить» вместо вечного спиннера;
  база снова в порядке → «Повторить» → статистика.
- **9.10.2** То же в «Истории».
- **9.10.3** Страница операции, которой уже нет (старое уведомление) → «Операция не найдена: возможно, её удалили.».
- **9.10.4** «Уведомлять о лимитах» не сохранилось → тост «⚠️ Не удалось сохранить», переключатель вернулся.
- Курсы валют (logic `fx.test.ts`): запрос дольше 10 с брошен; без сети день не спрашивается 10 минут, после пачки из 4
  неудач остальные дни не пробуются; ответ НБГ за другой день не сохраняется.

**9.9 Резервная копия** — «Настройки» → «Резервная копия» → лист: «Все операции, категории, мерчанты и план — одним
файлом…»; переключатель «Автокопия» (под ним — что сейчас); включён — радиокнопки «Google Диск» («Вход через Google;
пароль обязателен.») / «Локально» («В папку на телефоне; пароль — по желанию.»), по умолчанию «Локально», и кнопка
«Сохранить» — только пока выбор не сохранён; автокопия уже включена — «Сохранить» нет, другая радиокнопка переводит
туда сразу, ссылки «Сменить папку» / «Сменить аккаунт», «Сменить пароль» (пароль задан). Выключить — «Выключить
автокопию?». Своего пункта у пароля нет. Под разделом кнопки «Восстановить из
копии», «Экспорт копии», «Экспорт CSV». Системные диалоги файлов — нативный модуль (в тестах замокан), проверка файла —
`logic/backup.test.ts`.
- **9.9.1** «Экспорт копии» → «Пропустить» → диалог сохранения закрыт без выбора → ничего не сказано.
- **9.9.2** «Экспорт копии» → пароля нет — окно пароля с «Пропустить» → копия базы предложена как `budget-ГГГГ-ММ-ДД.db`
  → тост «Копия сохранена».
- **9.9.24** «Экспорт копии» → в окне задать пароль → копия сохранена зашифрованной; пароль задан — окна нет (9.9.9).
- **9.9.3** «Восстановить из копии» → «Откуда восстановить?» → «Из файла» → файл подходит → «Восстановить из копии?»
  («…заменятся данными из файла. Приложение перезапустится.») → «Восстановить» → файл встаёт на место базы.
- **9.9.4** Файл не подходит → «Этот файл не подходит» и причина (не копия, повреждён, другое приложение, новая версия);
  база не тронута.
- **9.9.5** «Экспорт CSV» → `operations-ГГГГ-ММ-ДД.csv` (Дата;Сумма;Валюта;Тип;Категория;Раздел;Мерчант;Описание) (разделённая операция — строка на каждую часть, первой её основная категория) → тост
  «Таблица операций сохранена».
- **9.9.6** Автокопия выключена («Раз в неделю — копия в выбранную папку.»), радиокнопок нет → включить → «Локально»
  выбрано, «Сохранить» (папка ещё не спрошена) → «Сохранить» → выбор папки → пароль («Пропустить») → первая копия сразу
  (`budget-auto-ГГГГ-ММ-ДД-ЧЧММ.db`, в папке остаются две последние) → «Автокопия включена», «Сохранить» скрыта, «Раз в
  неделю в папку «Download», хранятся две последние. Последняя — сегодня.», «Сменить папку». Выключить → «Выключить
  автокопию?» («Новые копии перестанут сохраняться. Уже сохранённые останутся в папке.» / «…на Google Диске.») →
  «Выключить» → «Автокопия выключена», доступ к папке отдан.
- **9.9.25** Выключить → «Выключить автокопию?» → «Отмена» → остаётся включённой.
- **9.9.26** Включить и не сохранить → выключить — без вопроса, радиокнопки и «Сохранить» скрыты.
- **9.9.7** При открытии приложения: копия через неделю после прошлой, не раньше; не сохранилась → тост «Автокопия не
  сохранилась: выберите папку заново».
- **9.9.8** включить → «Сохранить» → папка → окно пароля: «Пароль» и «Повторите пароль»: короче 8 символов → тост
  «Пароль — не короче 8 символов»; разные → «Пароли не совпадают»; верно — задан, автокопия включена.
- **9.9.9** Пароль задан → «Экспорт копии» сохраняет зашифрованный файл, пароль не спрашивается.
- **9.9.11** Пароль задан → автокопия ложится в папку зашифрованной.
- **9.9.12** включить → «Сохранить» → папка не выбрана → ничего не задано, «Сохранить» остаётся.
- **9.9.13** «Сменить папку» → новая папка, доступ к старой отдан, копия в новую — сразу, «Автокопия включена».
- **9.9.14** Пароль задан → «Сменить пароль» → окно: «Новые копии будут зашифрованы новым паролем. Уже сохранённые
  останутся со старым — для них запомните и его…» → новый пароль дважды → «Пароль для копий задан»; пароля нет («Локально») — вместо неё «Задать пароль»: пароль дважды → «Пароль для копий задан», дальше копии шифруются.
- **9.9.15** включить → «Google Диск» → «Сохранить» → вход в Google → пароля нет — «Задать пароль» дважды → первая копия зашифрована
  и ушла на Диск (`budget-auto-ГГГГ-ММ-ДД-ЧЧММ.db.enc`, хранятся 4) → тост «Автокопия — на Google Диске»; «Аккаунт …;
  пароль обязателен.», «Раз в неделю на Google Диск (…), хранятся четыре последние.», «Сменить аккаунт», «Сменить пароль».
- **9.9.16** Окно пароля закрыто («Отмена») → Диск не включился, на Диск ничего не ушло, «Сохранить» остаётся.
- **9.9.18** При открытии приложения раз в неделю копия — на Диск (не в папку); не ушла → тост «Автокопия не ушла на
  Google Диск: нет сети или доступа к аккаунту».
- **9.9.19** «Восстановить из копии» → «Откуда восстановить?» → «С Google Диска» → «Какую копию восстановить?» (даты) →
  скачана → «Пароль копии» → «Восстановить из копии?» → встаёт на место базы.
- **9.9.22** включить → «Сохранить» → папка → сразу окно пароля (пароля нет): задать — первая копия зашифрована;
  «Пропустить» (вместо «Отмены») — без пароля (9.9.6). «Сменить папку» пароль не спрашивает.
- **9.9.23** включить → «Google Диск» → «Сохранить» → вход → пароль без «Пропустить» (только «Отмена» — 9.9.16).
- **9.9.21** Копии на Диске → «Локально» (без «Сохранить» — сразу) → папка → копия в папку, «Локально» выбрано.
- **9.9.20** На Диске копий нет → «На Google Диске копий нет», «В аккаунте … копий этого приложения нет.».
- **9.9.10** Зашифрованная копия → «Восстановить из копии» → «Пароль копии»: неверный → тост «Неверный пароль», снова
  спрашивает; верный → «Восстановить из копии?» → копия расшифрована и встаёт на место базы.

**9.11 Блокировка** — «Настройки» → переключатель «Блокировка» (выключена — «Приложение открывается без входа»).
Нативный модуль (хеш PIN-кода, системное окно отпечатка) в тестах — его замена в памяти; системное окно
и настоящее сворачивание — вручную ([e2e/plan/9-general.md](../../e2e/plan/9-general.md)).
- **9.11.1** Включить → «Придумайте PIN-код» («От 4 до 6 цифр»), «Дальше» — от 4 цифр → «Подтвердите PIN-код» («Введите
  его ещё раз»): не тот → «PIN-коды не совпадают — введите ещё раз» и «Придумать заново»; тот → без датчика сразу тост
  «Блокировка включена», под переключателем «Вход по PIN-коду» и «Настроить» → «Настройки» закрываются, окно
  «Блокировка»: «Спрашивать после сворачивания» (Всегда — по умолчанию / 1 мин / 5 мин / 15 мин), «Скрывать суммы в уведомлениях»,
  «Сменить PIN-код»; строки «Отпечаток или лицо» нет.
- **9.11.2** ✕ («Отмена») при создании PIN-кода → блокировка остаётся выключенной.
- **9.11.3** Есть датчик → после PIN-кода «Входить по отпечатку?» → «Включить отпечаток» → системное окно → «Блокировка
  включена», «Вход по PIN-коду или отпечатку». «Не сейчас» → только PIN-код.
- **9.11.4** Приложение свернули: выбрано «1 мин»: вернулись раньше — входа нет;
  позже — «Введите PIN-код» и «Забыли PIN-код?». Неверный → «Неверный PIN-код. Осталось попыток: 4»; пятый неверный →
  «Слишком много попыток. Подождите 30 секунд», цифры не нажимаются. Верный → приложение. «Всегда» — вход при каждом
  возвращении.
- **9.11.5** Отпечаток включён → при возвращении сразу системное окно; узнал → приложение без PIN-кода.
- **9.11.6** Выключить → «Выключить блокировку», «Введите PIN-код», «Приложение будет открываться без входа»: ✕ —
  остаётся включённой; верный PIN-код → «Блокировка выключена», PIN-код забыт.
- **9.11.7** «Настроить» → «Сменить PIN-код» → «Текущий PIN-код» → «Новый PIN-код» → «Подтвердите PIN-код» → «PIN-код изменён».
- **9.11.8** Глазик в «Статистике»: скрыть — сразу; показать — «Показать суммы» и PIN-код (или отпечаток).

**9.12 Банки** — «Настройки» → «Банки».
- Карточка банка: значок, название, переключатель «Читать …»; «SMS от» («TBC SMS» / «BOG»), «Уведомления» (приложение
  банка), «Разбор» («встроенный» у TBC, «шаблоны сообщений · N» у Bank of Georgia), «Баланс карты» (или «—»). Есть
  сообщения банка в «Не распознано» — «N сообщений в «Не распознано» — отметьте одно, и такие начнут читаться» (ведёт туда).
- Сначала читается только TBC. Включили Bank of Georgia → в «Операциях» «Балансы карт» строкой на банк (нет баланса —
  «после SMS с балансом», «—»), кнопка фильтра «Банк», у операций метка банка («TBC», «BoG») рядом с мерчантом.
- «Импорт SMS из телефона» говорит, из каких банков: «Из банка: TBC» / «Из банков: TBC, Bank of Georgia», ссылка «Другие
  банки — в «Банках» ›» закрывает лист и открывает «Банки».
- Выключить последний читаемый банк нельзя: «Хотя бы один банк должен читаться».
- SMS и пуши выключенного банка не читаются (нативная часть их не пропускает); его операции остаются.
- Сообщения Bank of Georgia — в «Не распознано» с пометкой «SMS · BANK OF GEORGIA»; шаблон из такого читает только его
  сообщения, операции и баланс — банка BoG.
- Категория «🔁 Между своими картами» (переводы, системная): перевод и пополнение в ней — не траты и не доход; есть среди
  кнопок уведомления о переводе / пополнении.


**9.13 Обновление** — новая версия приложения из последнего релиза на GitHub (сборка «1.0.N»; локальная «1.0-dev» не
проверяет).
- **9.13.1** Запуск, на GitHub версия новее → тост «Доступна версия 1.0.N» с «Обновить» (один раз на версию) → APK
  скачан и отдан системной установке.
- **9.13.2** «Настройки» → внизу «Версия 1.0.M» и «Обновить до 1.0.N» → пока скачивается — «Скачивается… N%» → системная
  установка.
- **9.13.3** Нет разрешения на установку → «Разрешите установку» («…«Установка неизвестных приложений»…») → «Открыть
  настройки» — системный переключатель для Budget; скачивания нет.
- **9.13.4** Новее нет → «Версия 1.0.N · последняя», кнопки нет.
- **9.13.5** Не скачалось → тост «⚠️  Не удалось скачать обновление».
- **9.13.6** Версия, показанная тостом, отмечена для ежедневной проверки — уведомления о ней не будет (8.6.1).
- **9.13.7** Открыто уведомлением об обновлении → сразу тост «Скачивается…», скачивание и установка; тоста «Доступна
  версия» нет.
- **9.13.8** То же, когда приложение тут же возвращается в активное состояние (две проверки разом — одна): тоста нет,
  скачивание одно.
- **9.13.9** Версия, о которой было уведомление, при открытии приложения тостом не показывается.
