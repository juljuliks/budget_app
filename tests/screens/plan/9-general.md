# План тестов · 9. Общее · тесты экранов (Jest)

Обозначения, Дано / Шаги / Ожидается и где что проверяется — [tests/README.md](../../README.md).

**9.2 Стартовые категории**
- Чистая установка: «Продукты», «Кафе и рестораны», «Транспорт», «Такси», «Дом и коммуналка», «Здоровье», «Подписки», «Покупки», «Развлечения», «Путешествия», «Переводы», «Другое»; системные «Пополнение счёта» и «Между своими картами».
- Раздел «Переводы».

**9.3 Обновление** — база прошлой версии (seed на старой схеме) → после запуска данные на месте, миграции применены.
**9.4 Стартовая вкладка** — запуск всегда на «Операциях».
**9.5 Шестерёнка** — в шапках обеих вкладок → страница «Настройки» (стрелка «назад» в шапке; «Банки», «Мерчанты»,
«Категории», «Шаблоны сообщений» открываются поверх неё, «Назад» возвращает к ней; импорт, резервная копия и «Настроить»
блокировки — шиты на ней): «Валюта», «Уведомлять о лимитах», «Блокировка», «Банки», «Мерчанты», «Категории», «Шаблоны сообщений», «Импорт SMS из телефона», «Резервная копия»; внизу — «Версия 1.0.N» (в тестах — «Версия dev»).
**9.7 Без сети** — статистика без курса показывает «Не учтено — нет курса…», приложение не падает.
**9.8 Ошибки сохранения** — при ошибке базы тосты «Не удалось сохранить» / «Не удалось удалить», данные не испорчены.

**9.10 Не загрузилось**
- **9.10.1** Статистика не прочиталась (ошибка базы) → «Не удалось загрузить» и «Повторить» вместо вечного спиннера;
  база снова в порядке → «Повторить» → статистика.
- **9.10.2** То же в «Истории».
- **9.10.3** Карточка операции, которой уже нет (старое уведомление) → «Операция не найдена: возможно, её удалили.».
- **9.10.4** «Уведомлять о лимитах» не сохранилось → тост «⚠️ Не удалось сохранить», переключатель вернулся.
- Курсы валют (logic `fx.test.ts`): запрос дольше 10 с брошен; без сети день не спрашивается 10 минут, после пачки из 4
  неудач остальные дни не пробуются; ответ НБГ за другой день не сохраняется.

**9.9 Резервная копия** — «Настройки» → «Резервная копия» → лист: «Все операции, категории, мерчанты и план — одним
файлом…», переключатели «Автокопия» и «Пароль для копий» (под каждым — что сейчас), под ними кнопки «Сохранить
копию», «Восстановить из копии», «Экспорт CSV». Системные диалоги файлов — нативный модуль (в тестах замокан),
проверка файла — `logic/backup.test.ts`.
- **9.9.1** Диалог сохранения закрыт без выбора → ничего не сказано.
- **9.9.2** «Сохранить копию» → копия базы предложена как `budget-ГГГГ-ММ-ДД.db` → тост «Копия сохранена».
- **9.9.3** «Восстановить из копии» → файл выбран и подходит → «Восстановить из копии?» («…заменятся данными из
  файла. Приложение перезапустится.») → «Восстановить» → файл встаёт на место базы.
- **9.9.4** Файл не подходит → «Этот файл не подходит» и причина (не копия, повреждён, другое приложение, новая версия);
  база не тронута.
- **9.9.5** «Экспорт CSV» → `operations-ГГГГ-ММ-ДД.csv` (Дата;Сумма;Валюта;Тип;Категория;Раздел;Мерчант;Описание) (разделённая операция — строка на каждую часть, первой её основная категория) → тост
  «Таблица операций сохранена».
- **9.9.6** «Автокопия» выключена («Раз в неделю — копия в выбранную папку.») → включить → окно «Раз в неделю, когда вы
  открываете приложение…» → «Выбрать папку» (отмена — переключатель остаётся выключенным) → первая копия сразу
  (`budget-auto-ГГГГ-ММ-ДД-ЧЧММ.db`, в папке остаются две последние) → «Автокопия включена», переключатель включён, под
  ним «Раз в неделю в папку «Download», хранятся две последние. Последняя — сегодня.» и «Сменить папку». Выключить →
  «Автокопия выключена», доступ к папке отдан.
- **9.9.7** При открытии приложения: копия через неделю после прошлой, не раньше; не сохранилась → тост «Автокопия не
  сохранилась: выберите папку заново».
- **9.9.8** «Пароль для копий» выключен («Копии не шифруются.») → включить → окно → «Задать пароль» → «Пароль» и «Повторите пароль»: короче 8 символов → тост
  «Пароль — не короче 8 символов»; разные → «Пароли не совпадают»; верно → «Пароль для копий задан».
- **9.9.9** Пароль задан (переключатель включён, «Копии шифруются: без пароля их не восстановить.», «Сменить пароль»;
  выключить — «Пароль для копий убран») → «Сохранить копию» сохраняет зашифрованный файл.
- **9.9.11** Пароль задан → автокопия ложится в папку зашифрованной.
- **9.9.12** Включить «Автокопию» или «Пароль для копий» → в окне «Отмена» → переключатель остаётся выключенным.
- **9.9.13** «Сменить папку» → новая папка, доступ к старой отдан, копия в новую — сразу, «Автокопия включена».
- **9.9.14** «Сменить пароль» → новый пароль дважды → «Пароль для копий задан»; выключить → «Пароль для копий убран»,
  «Копии не шифруются.».
- **9.9.10** Зашифрованная копия → «Восстановить из копии» → «Пароль копии»: неверный → тост «Неверный пароль», снова
  спрашивает; верный → «Восстановить из копии?» → копия расшифрована и встаёт на место базы.

**9.11 Блокировка** — «Настройки» → переключатель «Блокировка» (выключена — «Приложение открывается без входа»).
Нативный модуль (хеш PIN-кода, системное окно отпечатка) в тестах — его замена в памяти; системное окно
и настоящее сворачивание — вручную ([e2e/plan/9-general.md](../../e2e/plan/9-general.md)).
- **9.11.1** Включить → «Придумайте PIN-код» («От 4 до 6 цифр»), «Дальше» — от 4 цифр → «Подтвердите PIN-код» («Введите
  его ещё раз»): не тот → «PIN-коды не совпадают — введите ещё раз» и «Придумать заново»; тот → без датчика сразу тост
  «Блокировка включена», под переключателем «Вход по PIN-коду» и «Настроить» → «Настройки» закрываются, окно
  «Блокировка»: «Спрашивать после сворачивания» (Всегда — по умолчанию / 1 мин / 5 мин / 15 мин), «Скрывать суммы в уведомлениях»,
  «Сменить PIN-код»; строки «Отпечаток или лицо» нет.
- **9.11.2** ✕ («Отмена») при создании PIN-кода → блокировка остаётся выключенной.
- **9.11.3** Есть датчик → после PIN-кода «Входить по отпечатку?» → «Включить отпечаток» → системное окно → «Блокировка
  включена», «Вход по PIN-коду или отпечатку». «Не сейчас» → только PIN-код.
- **9.11.4** Приложение свернули: выбрано «1 мин»: вернулись раньше — входа нет;
  позже — «Введите PIN-код» и «Забыли PIN-код?». Неверный → «Неверный PIN-код. Осталось попыток: 4»; пятый неверный →
  «Слишком много попыток. Подождите 30 секунд», цифры не нажимаются. Верный → приложение. «Всегда» — вход при каждом
  возвращении.
- **9.11.5** Отпечаток включён → при возвращении сразу системное окно; узнал → приложение без PIN-кода.
- **9.11.6** Выключить → «Выключить блокировку», «Введите PIN-код», «Приложение будет открываться без входа»: ✕ —
  остаётся включённой; верный PIN-код → «Блокировка выключена», PIN-код забыт.
- **9.11.7** «Настроить» → «Сменить PIN-код» → «Текущий PIN-код» → «Новый PIN-код» → «Подтвердите PIN-код» → «PIN-код изменён».
- **9.11.8** Глазик в «Статистике»: скрыть — сразу; показать — «Показать суммы» и PIN-код (или отпечаток).

**9.12 Банки** — «Настройки» → «Банки».
- Карточка банка: значок, название, переключатель «Читать …»; «SMS от» («TBC SMS» / «BOG»), «Уведомления» (приложение
  банка), «Разбор» («встроенный» у TBC, «шаблоны сообщений · N» у Bank of Georgia), «Баланс карты» (или «—»). Есть
  сообщения банка в «Не распознано» — «N сообщений в «Не распознано» — отметьте одно, и такие начнут читаться» (ведёт туда).
- Сначала читается только TBC. Включили Bank of Georgia → в «Операциях» «Балансы карт» строкой на банк (нет баланса —
  «после SMS с балансом», «—»), кнопка фильтра «Банк», у операций метка банка («TBC», «BoG») рядом с мерчантом.
- «Импорт SMS из телефона» говорит, из каких банков: «Из банка: TBC» / «Из банков: TBC, Bank of Georgia», ссылка «Другие
  банки — в «Банках» ›» закрывает лист и открывает «Банки».
- Выключить последний читаемый банк нельзя: «Хотя бы один банк должен читаться».
- SMS и пуши выключенного банка не читаются (нативная часть их не пропускает); его операции остаются.
- Сообщения Bank of Georgia — в «Не распознано» с пометкой «SMS · BANK OF GEORGIA»; шаблон из такого читает только его
  сообщения, операции и баланс — банка BoG.
- Категория «🔁 Между своими картами» (переводы, системная): перевод и пополнение в ней — не траты и не доход; есть среди
  кнопок уведомления о переводе / пополнении.
