### 8.1 Новая операция без категории

**8.1.1 Покупка**
- Заголовок «Покупка — 44.00 ₾», текст — мерчант.
- Кнопки: 2 самые используемые категории (не «Переводы») и «➡️ К категориям».

**8.1.2 Перевод**
- «Перевод — 25.00 ₾»; кнопки — категории раздела «Переводы».

**8.1.3 Мерчант с разными категориями**
- Текст «WOLT · выберите категорию»; кнопки — его категории первыми.

**8.1.4 Возврат без категории** — «Возврат — 94.78 ₾», «TEMU.COM · без категории», без кнопок.

**8.1.8 Повтор** — одно уведомление на операцию (новое заменяет).

**8.1.9 Операция с категорией** — уведомления «без категории» нет.

### 8.2 Отчёт за месяц

**8.2.1 Время** — запланировано на 10:00 1-го числа следующего месяца; заголовок «Отчёт за сентябрь».
**8.2.2 Текст** — «Отложено X ₾ (≈ Y ₾ за год). Могли ещё Z ₾» / «Бюджет превышен на X ₾» / «Потрачено X ₾».
**8.2.3 Перепланирование** — новая операция до 1-го → уведомление пересчитано (одно на месяц).
**8.2.4 Месяц без плана** — нет бюджета и сумм в плане → уведомление не запланировано, даже если были траты.
Был план, и его убрали → ранее запланированное уведомление отменено.
Месяц с планом и без трат → уведомление есть.
**8.2.5 Тап** → «Статистика» и лист отчёта за тот месяц.

### 8.3 Лимиты (Настройки → «Уведомлять о лимитах», по умолчанию вкл)

**8.3.1 80% плана месяца**
- «🛒 Продукты — 80% плана на октябрь», «Потрачено 240 ₾ из 300 ₾, осталось 60 ₾ на 23 дня».

**8.3.2 100% плана** — «… — план на октябрь превышен», «Потрачено 310 ₾ из 300 ₾, перерасход 10 ₾».

**8.3.3 Лимит ритма**
- Дневной: «… — 80% лимита на день», «Сегодня потрачено X из Y, осталось Z».
- Недельный: «… — лимит на неделю превышен», «5 – 11 окт: потрачено X из Y».

**8.3.4 Один раз** — каждый порог раз за месяц (для плана) или окно (для ритма); следующая операция не повторяет.
**8.3.5 Приоритет** — одновременно месяц 100% и ритм 100% → про месяц.
**8.3.6 Не лимиты** — обязательные платежи и категории без плана — без уведомлений.
**8.3.7 Выключено** — уведомлений нет.
**8.3.8 Тап** → «Статистика».
