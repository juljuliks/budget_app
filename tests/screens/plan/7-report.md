# План тестов · 7. Отчёт за месяц и история · тесты экранов (Jest)

Обозначения, Дано / Шаги / Ожидается и где что проверяется — [tests/README.md](../../README.md).

### 7.1 Отчёт

Отчёт есть только у прошедшего месяца с планом: задан бюджет или хотя бы одна категория в плане с суммой больше 0.
Категория в плане с суммой 0 планом не считается.

**7.1.0 Месяц без плана — отчёта нет нигде**
- Дано: прошлый месяц с операциями, без бюджета и без сумм в плане.
- Ожидается:
  - в статистике этого месяца нет строки отчёта;
  - в «Истории» у месяца нет «Отчёт за месяц ›»;
  - уведомление об отчёте за этот месяц не запланировано (8.2.4).
- То же с категорией в плане с суммой 0 — отчёта нет.

**7.1.0a Месяц только с суммами в плане, без бюджета**
- Дано: прошлый месяц, «Продукты» 300 ₾ в плане, бюджета нет.
- Ожидается: строка отчёта «Потрачено X ₾», «Отчёт за месяц ›» в истории; в листе «Бюджет месяца не задан: …»,
  перерасход лимитов в «Что можно улучшить».

**7.1.0b План убрали**
- Дано: у прошлого месяца был план, уведомление об отчёте запланировано. Шаги: убрать бюджет и суммы.
- Ожидается: строка отчёта и ссылка в истории пропали; запланированное уведомление отменено при следующей операции.
- Старое уведомление открыто после этого → лист «Отчёт · …» с текстом «Плана на этот месяц не было — отчёта нет.».

**7.1.0c Текущий месяц** — строки отчёта и ссылки нет, даже с планом (месяц не закончился).

**7.1.1 Строка отчёта** (прошлый месяц с планом, в статистике и в истории)
- «Отложено X ₾ · могли ещё Y ₾» / «Бюджет превышен на X ₾» / без бюджета «Потрачено X ₾».

**7.1.2 Лист «Отчёт · Сентябрь 2026»**
- Только суммы в плане, без бюджета: «Бюджет месяца не задан: потрачено X. Задайте бюджет в плане, чтобы видеть, сколько откладывается.».
- Отложено: «В сбережения» (или «Отложено») крупно, «≈ X в год» с ⓘ («Как посчитано»: среднее до 3 месяцев с бюджетом и полными данными × 12).
- «На X больше / меньше, чем месяцем раньше» (только если у обоих месяцев есть данные с первой половины).
- Разбивка, сумма строк = отложенному:
  - «🔒 Сразу»;
  - «Категории плана потратили меньше / больше»;
  - «Не потрачено из доли вне плана» / «Вне плана сверх доли»;
  - «Свободно в плане» (красным);
  - «Из них переведено в «Сбережения» вручную».
- Превышен: «Бюджет превышен на X», «Потрачено X при бюджете Y».

**7.1.3 «Что можно улучшить»**
- Заголовок «≈ −X в год» с ⓘ.
- Перерасход лимитов больше 5% плана: строки «план X, факт Y», «−Z». Меньше 5% не показывается.
- Вне плана сверх доли: «Доля X, потрачено Y · N% всех трат».
- Вне плана больше 25% трат или доля превышена больше чем на 20% → «Если эти траты повторяются, их стоит запланировать» и 3 крупнейшие категории с «＋ В план».
- «Без категории: N операций» → «Разметить» (операции без категории за месяц).
- Обязательные без операций (есть данные за месяц) → «нет операции за месяц».
- Траты зашли в отложенное → строка с ⓘ.
- «Отложено меньше, чем месяцем раньше».

**7.1.4 «Что уже хорошо»**
- «≈ +X в год».
- «✓ Отложенное не тронуто: 🔒 X», «✓ Лимиты категорий соблюдены», «✓ Вне плана в пределах доли: X из Y».
- Категории, сэкономившие в плане, «+Z».
- Переведено в «Сбережения» вручную.
- «Отложено больше, чем месяцем раньше».

**7.1.5 Мало данных** — месяц, где первая операция после 15-го числа: без сравнения с прошлым и без «не оплачено».

### 7.2 История

**7.2.1** Месяцы от первой операции или плана до текущего, новые сверху: «План», «Потрачено», «Осталось» / «⚠ Перерасход», полоса.
**7.2.2** С бюджетом: «Бюджет», «Свободно», «Сэкономлено» (зелёным) / «⚠ Перерасход».
**7.2.3** Тап по месяцу → траты по категориям (⚠ у превышенных); тап по категории → «Операции».
**7.2.4** Прошлые месяцы с планом (бюджет или сумма в плане) — «Отчёт за месяц ›» → лист отчёта; без плана ссылки нет.
