# План тестов · 6. План · тесты экранов (Jest)

Обозначения, Дано / Шаги / Ожидается и где что проверяется — [tests/README.md](../../README.md).

### 6.1 Бюджет месяца

**6.1.1 Без бюджета**
- «Бюджет месяца 0 ₾» с карандашом.
- Текст «Укажите бюджет месяца (например, зарплату): план не сможет его превысить, а у категорий появятся доли в %».

**6.1.2 Задать**
- Карандаш → лист «Бюджет месяца».
- Подсказка «Сколько денег на месяц, например зарплата. План не сможет его превысить.» или «Уже запланировано: X» / «Пришло за месяц: X» («Пополнение счёта» и переводы, по которым вернули больше).
- Ввод 3000 → «Сохранить» → тост «Бюджет месяца сохранён».

**6.1.3 Убрать** — 0 или пусто → тост «Бюджет месяца убран»; отложенное и своя доля сброшены.

**6.1.4 Меньше запланированного**
- Запланировано 2500, бюджет 2000 → «По категориям уже запланировано 2 500 ₾ — бюджет не может быть меньше.».
- С отложенным или долей → «… — вместе с отложенным и долей вне плана это больше бюджета.».

**6.1.5 Другая валюта** — бюджет 1000 $ при показе в ₾ → сверху сумма в ₾, под ней «1 000.00 $».

**6.1.6 Полоса бюджета**
- Под полосой — легенда, строка на часть: точка, «План», «Вне плана», «Копилки», «Сбережения» (или «Свободно» зелёным, если «Что останется — в сбережения» выключен), справа % и сумма.
- Строки «Вне плана» нет без доли, «Копилки» — без копилок.

**6.1.7 Замок на отложенном**
- Отложенная часть тёмная, по центру круг с 🔒: 60% её ширины, не выше двух высот полосы.
- Часть уже 10 / 0.6 px → без круга.

**6.1.8 Прогноз** (текущий месяц, остаток в сбережения)
- Перерасход уменьшил сбережения больше чем на 1% бюджета → «Сбережения к концу месяца ≈ X ₾, если тратить по плану».
- Ушли в ноль → «Перерасход съел сбережения месяца».

**6.1.9 Прошлый месяц** — «Сбережения» = бюджет − потрачено; отрицательное красным.
**6.1.10 Следующий месяц** — можно открыть стрелкой (на месяц вперёд); дальше нельзя.

**6.1.11 Перенос в новый месяц**
- Первый заход в новый месяц копирует бюджет, валюту, долю, отложенное, «Что останется — в сбережения».
- Категории с 📌 переносятся с суммой, остальные с 0 и подсказкой «в прошлом месяце X ₾».
- Прошлые месяцы при просмотре не создаются.

### 6.2 Отложить сразу и траты вне плана (в листе бюджета)

**6.2.1 Отложить сразу, %**
- «🔒 Отложить сразу», переключатель «%» / «₾», слайдер 0–50% с шагом 10.
- Подсказка «300 ₾ сразу в сбережения: план и траты вне плана их не займут.».
- Остановки, которые не помещаются, бледные.

**6.2.2 Своя сумма** — «₾» → поле суммы; сумма не на остановке открывается в режиме суммы; обратно в % — ближайшая остановка, которая помещается.
**6.2.3 Не помещается** — «Не помещается: свободно X ₾ — остальное занято планом и долей вне плана.» красным.
**6.2.4 На траты вне плана** — то же; подсказка «X ₾ на траты вне плана — план их не займёт.»; хранится как % на остановке, иначе как сумма.

**6.2.5 Что останется — в сбережения**
- Переключатель, текст «Что не запланировано и не потрачено, откладывается в категорию «Сбережения». Запоминается на следующие месяцы.».
- Выключен → «Свободно» и отдельная строка «Отложено».

**6.2.6 Системные разделы плана**
- «Сбережения»: «🔒 Сразу · заблокировано в начале месяца · N% бюджета» и «🌊 Что осталось · что не запланировано, плюс сэкономленное».
- «Вне плана»: «🎲 Траты вне плана · категории без плана и без категории».
- Тап по ним → лист бюджета.

### 6.3 Категории в плане

**6.3.1 Пустой план** — «План пуст. Нажмите ＋, чтобы добавить категории и суммы.»; подпись «📌 — переходит в следующий месяц с той же суммой».

**6.3.2 Добавить несколько**
- «＋» → лист: «Свободно: X ₾» (или «Бюджет месяца не задан»), все категории не в плане, кроме «Сбережений», с полем суммы и валютой.
- Ввод суммы отмечает строку; отмеченная без суммы берёт прошлую сумму (в подсказке поля).
- «· выбрано на X ₾»; «Добавить (3)» → тост «Добавлено в план: 3 категории» (одна — ««…» добавлена в план»).
- Больше свободного → «Больше бюджета месяца: свободно X ₾».

**6.3.3 Сумма категории**
- Тап по строке → лист с названием категории:
  - сумма и валюта;
  - «Траты с лимитом» / «Обязательный платёж»;
  - для лимита ритм: «Каждый день · ≈ 15 ₾ в день», «Раз в неделю», «Раз в 2 недели», «Крупно, раз в месяц».
- Подсказки: «Можно запланировать до X», «В плане на сентябрь X», «В среднем в месяц (3 полных месяца) ≈ X» (по последним полным месяцам).
- «Сохранить» → тост «План «…» сохранён».

**6.3.4 Больше бюджета** — «Больше бюджета месяца: можно запланировать до X ₾»; не сохранено.

**6.3.5 Строка плана**
- Сумма справа (в другой валюте — под ней исходная).
- Подпись «лимит ≈ 46 ₾ в неделю · 12% бюджета» / «обязательный платёж · …» / «крупно, раз в месяц».

**6.3.6 📌 Повторять**
- Тап по 📌 → тост ««…» будет повторяться каждый месяц» / ««…» больше не повторяется».

**6.3.7 Удалить из плана**
- «Удалить из плана» в листе суммы.
- Без 📌 → сразу, тост ««…» убрана из плана» с «Отменить» → ««…» снова в плане», пункт как был (сумма, валюта, «Как тратите»).
- С 📌 → «Убрать «…» из плана?», «Эта категория повторяется каждый месяц (📌). Она пропадёт из плана этого месяца и не перейдёт в следующие. Операции не изменятся.».

**6.3.8 «＋ В план» из статистики**
- Лист суммы с текущими тратами категории.
- Сохранение добавляет в план месяца, статистика обновилась.

**6.3.9 Разделы плана** — категории по разделам с «· N%» бюджета у раздела.

### 6.5 Копилки

**6.5.1 Сделать копилку**
- Дано: план с бюджетом 3 000 ₾, «👕 Одежда» 400 ₾, в октябре ZARA 450 ₾.
- Шаги: «Изменить: 👕 Одежда» → «Копилка».
- Ожидается: над полем — «Накопить»; «К какой дате» — «Не выбрана», «Выбрать»; «Уже отложено (необязательно)»;
  «Выберите дату — посчитаем взнос в месяц», «Сохранить» неактивна.
- Шаги: 1500, уже отложено 300, «Выбрать» → календарь с ноября (раньше нельзя) → 31 января 2027 → «Выбрать».
- Ожидается: «31 января 2027 · через 4 месяца», «300 ₾ в месяц · 4 месяца»; «Сохранить» → «Копилка «👕 Одежда» сохранена».
- В плане: строка «Копилки» под полосой бюджета, раздел «Копилки», строка «150 из 1 500 ₾ · к 31 января 2027», «300 ₾» «в месяц».
- Взнос больше свободного → «Взнос больше бюджета месяца: можно запланировать до X ₾. Выберите дату позже».

**6.5.2 Карточка копилки** — тап по строке: «150 ₾» «из 1 500 ₾», «К 31 января 2027 · ещё 3 взноса», «300 ₾ в месяц»;
«Взносы и траты»: «Октябрь · ZARA −450 ₾», «Октябрь · взнос, идёт +300 ₾», «Октябрь · уже отложено +300 ₾»;
«Изменить» — лист категории с копилкой.

**6.5.3 Удалить копилку**
- «Удалить копилку» → «Удалить копилку «👕 Одежда»?», «Накоплено 150 ₾ — они перейдут в сбережения октября. Категория
  останется, её траты пойдут вне плана, пока вы не добавите её в план снова.».
- «Удалить» → тост «Копилка «👕 Одежда» удалена» с «Отменить» → «Копилка «👕 Одежда» снова в плане».
- В «Истории» у октября в «Сбережениях» — «Из копилки «👕 Одежда»».

**6.5.4 Статистика** — «Из копилок 450 ₾ — не из бюджета месяца» под итогом месяца; раздел «Копилки»: «450 / 600 ₾»,
«в копилке 150 ₾»; трат больше, чем в копилке, — «Не хватило X — взяты из бюджета октября», разница в «Потрачено».

**6.5.5 Месяц без плана** — взноса нет, следующие месяцы с планом считают взнос заново (больше). В «Истории» у месяца —
«В копилки X ₾».

**6.5.6 Операция в категории копилки** — в карточке «Из копилки — не из бюджета месяца», «в копилке было X → осталось Y»;
пришла по SMS сразу в эту категорию — уведомление «−1 200 ₾ · TURKISH AIRLINES», «🏖 Отпуск · из копилки, осталось 0 ₾».
