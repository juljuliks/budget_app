# Budget

Личный бюджет на Android, без сервера: приложение само читает SMS и уведомления банка (TBC), раскладывает
операции по категориям и показывает, сколько потрачено против плана месяца. Все данные — в SQLite на телефоне.

**Документация:** [Документация Budget](https://claude.ai/artifact/7deJ2vgzirC8qzhTz63hbj)

## Что умеет

- **Операции** — из SMS и пушей банка (одна покупка по SMS и пушу — одна операция), импорт SMS из телефона,
  ручные операции; поиск, фильтры, группировки (по дням, мерчантам, категориям, месяцам, типу, сумме),
  мультивыбор, баланс карты из последнего SMS.
- **Категории и мерчанты** — категория мерчанта назначается новым операциям автоматически, мерчант может быть
  с разными категориями; разделы, объединение и удаление категорий (с переносом операций месяца).
- **Уведомления** — о новой операции без категории с кнопками категорий, о лимитах, отчёт за месяц 1-го числа.
- **План** — бюджет месяца, «Отложить сразу» (🔒), доля на траты вне плана, категории с лимитом (день, неделя,
  2 недели, месяц) и обязательные платежи.
- **Статистика** — месяц, день, неделя, свой период, год; история месяцев, отчёт со сбережениями и тем, что
  можно улучшить; скрытие сумм, валюта показа.

## Стек

React Native 0.71 (TypeScript), react-native-quick-sqlite, notifee, react-navigation; Kotlin — приём SMS
(`SmsReceiver` + Headless JS), пушей банка (`BankPushListener`) и чтение SMS для импорта.

## Запуск

Нужны Node, Android SDK и JDK 17 (Gradle не работает с более новой Java).

```sh
npm ci
npm test               # Jest: логика (парсер, база, план, отчёт) и тесты экранов (всё приложение на SQLite в памяти)
npm run emulator       # сборка release и установка на эмулятор budget_pixel, запуск приложения
npm run apk            # APK на рабочий стол
npm run release        # релизная сборка
scripts/send_test_sms.sh        # тестовое SMS банка на эмулятор
scripts/e2e/run.sh              # Maestro на эмуляторе: только то, что без устройства не проверить (SMS, уведомления, импорт)
```

## Где что

| Путь | Что там |
|---|---|
| `src/parsers/` | разбор SMS банка |
| `src/ingest.ts`, `src/importer/` | приём SMS / пушей и импорт из телефона |
| `src/db/` | база: миграции, операции, категории, мерчанты, план, отчёты, курсы валют |
| `src/ui/` | экраны и листы; `src/ui/stats/` — статистика, план, отчёт |
| `src/notifications/` | уведомления и их кнопки |
| `android/app/src/main/java/com/budgetapp/` | нативная часть: SMS, пуши |
| `__tests__/` | Jest: логика; `__tests__/screens/` — тесты экранов |
| `scripts/e2e/` | Maestro, стартовые базы тестов и [план тестов](scripts/e2e/PLAN.md) |
