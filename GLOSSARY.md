# Глоссарий

Один термин на одно понятие во всём приложении. Общие слова и фразы — в `src/ui/strings.ts`.

| Понятие | Термин | Не использовать |
|---|---|---|
| Запись о движении денег (покупка, перевод, пополнение…) | **операция** (вкладка «Операции», «Новая операция») | транзакция |
| Вид операции: покупка, перевод, возврат… (фильтр в «Операциях») | **тип операции** (кнопка «Тип»; у пополнения и возврата — шит «Тип операции», карандаш «Сменить тип») | раздел (это группа категорий) |
| Возврат денег от мерчанта | **возврат**; погашенный в покупке — «✓ учтён в покупке»; без категории мерчанта — **«Возвраты без категории»** в статистике | — |
| Расход в статистике | **траты** («Потрачено», «все траты») | — |
| Где платили (магазин, бар, такси, сервис) | **мерчант** | магазин, продавец |
| Свой текст к операции; у ручной — введённый при добавлении (её название в списке) | **описание** («＋ Добавить описание») | заметка, комментарий |
| Сумма денег на месяц, которую раздаём по категориям | **бюджет месяца**; доля строки плана — процент под суммой («10%») | сумма к планированию, доход (в смысле бюджета) |
| Часть бюджета, ещё не отданная категориям | **свободно** | не распределено |
| Сумма категории на месяц | **план** («план на октябрь»); прошлый — «в прошлом месяце» | пункт, было |
| План, разложенный на день / неделю / 2 недели | **лимит на день / на неделю / на 2 недели** | норма |
| Как категория тратится (настройка) | **«Как тратите»**: каждый день / раз в неделю / раз в 2 недели / крупно, раз в месяц | норма считается за, ритм |
| Категории, где сумма меняется и за ней следит лимит (еда, бары, одежда) | **траты с лимитом** | гибкие, повседневные |
| Известная сумма один раз (подарок на день рождения, ремонт) | **разовый платёж** (вид в шите суммы плана: «Разовый платёж»); в статистике вместе с регулярными — группа **«Платежи»** («оплачено», «осталось оплатить») | обязательный платёж, фиксированные |
| Потрачено больше, чем можно | **перерасход** | сверх плана, сверх суммы, сверх нормы, превышено |
| Сколько ещё можно потратить | **осталось** | остаток (кроме остатка закончившегося месяца, см. ниже), можно потратить; «свободно» — только про бюджет |
| Не потрачено из лимита закончившегося периода (вчера, прошлая неделя) | **сэкономлено** | осталось (период уже прошёл), экономия |
| Не потрачено из бюджета за месяц (История) | **в сбережения** — «🔒 Отложено сразу» + «💰 Сэкономлено»; по итогам месяца остаток ещё **«Перенесено»** (на следующий месяц) или **сэкономлено** (у месяцев, подведённых до того, как «Оставить как есть» убрали); текущий месяц — «пока»; не подведён — сумма с «?» | сохранено |
| Не запланировано и не потрачено к концу месяца | **«💰 Сэкономлено»** (в плане — только если не 0); в итогах — строка раскладки, **«Перенести на октябрь»** / «В сбережения»; из плана октября — **«Куда остаток?»** («Перенести на октябрь» / «В сбережения»); в плане следующего — **«➕ Остаток сентября»** в разделе **«Перенос из сентября»** | свободно (это про план) |
| Ответы за закончившийся месяц (1-го числа): перерасход, сбережения | **итоги месяца** («Итоги · Сентябрь 2026», «Итоги сентября — удалось отложить?»); по шагам, **«Подвести позже»**, **«Подвести итоги ›»**, **«Изменить итоги ›»**; не ответили — **«Итоги не подведены»**, баннер **«Сентябрь не закрыт»**; на шаге «Сбережения» — **«За месяц»** или **«Остаток»**. «За месяц» — **«Сколько удалось отложить?»**: «Да, <осталось от бюджета>» / «Другая сумма» / «Нет». «Остаток» — поле в валюте бюджета месяца (прошлый остаток + что надо было отложить; правка — счёт): «В августе было …, по бюджету +… — по расчёту …», «За сентябрь +…», **«На N меньше расчёта»** / **«На N больше расчёта»**; прошлого нет — **«Прошлого остатка нет — его нужно ввести один раз»**, поле **«В августе было»**; раскладка — **«Разложим так»** / **«Разложили»** (копилки по ближнему сроку, «🔒 Отложено сразу», «💰 Сэкономлено»), вручную — **«Изменить распределение ›»** («Распределение · сентябрь», «Разложить заново») | закрыть месяц (в кнопках), подтвердить |
| Перерасход месяца, покрытый следующим | **«Из бюджета октября»**; в плане октября — **«⚠️ Перерасход сентября»** («вычтен из бюджета октября»), сменить — **«Покрыть иначе?»** («Из сбережений сентября», «Уже покрыт») | долг |
| Перерасход месяца, покрытый сбережениями | **«Из сбережений сентября»**: сначала 🔒, потом взносы копилок месяца (первой — с дальним сроком), остальное — **прошлые сбережения** (со счёта); подпись «🔒 300 ₾ → 200 ₾ · копилки −50 ₾ · прошлые сбережения −20 ₾», у копилки — «перерасход −N — следующие взносы станут больше», в «Остатке» — «на перерасход −N» | долг, из накоплений |
| Сумма плана больше свободного — взять разницу из «🔒 Отложить сразу» | **«Вычесть из сбережений?»** («Вычесть и сохранить» / «Вычесть и добавить»), тост «…из 🔒 вычтено N ₾» | занять, перераспределить |
| Добавление категории в план («＋») | **«Добавить в план»** по шагам: «Шаг 1 из 2 · Категория» («В плане сентября», «С тратами в октябре», «Остальные»), «Шаг 2 из 2 · Сумма» | — |
| Сбережения месяца меньше плана из-за перерасхода | в **статистике** за месяц — раздел **«Сбережения»** («К концу месяца, если дальше тратить по плану»; у 🔒, копилок, 💰 — «сейчас / план», **«Перерасход взял N ₾ ⓘ»**, у копилки — «— следующие взносы станут больше»; **«Из прошлых сбережений −N ⓘ»**); ⓘ — **«Сбережения меньше на …»** («Если дальше тратить по плану:» — «💰 сэкономлено N из M», «🔒 отложено N из M», «в копилки — на N меньше», «из прошлых сбережений уйдёт N»); плашка над статистикой — **«Перерасход зашёл в сбережения: −N · Подробнее ›»** (тот же шит); прошлый месяц — по итогам («✓ отложено», «отложено меньше на N», «Подвести итоги ›»); в плане — только отметки и строка под бюджетом (ниже); в отчёте — **«План» / «Факт»**, «Отложено» | прогноз; «Перерасход» в легенде плана |
| Насколько выполняется план (строка плана) | **отметка** под строкой: «потрачено N ₾», «✓ уложились», «больше на N ₾», «✓ оплачено» / «не оплачено» / «оплачено N из M», у 🔒 и 💰 — «✓ отложено» / «✓ выходит» / «выходит N — перерасход», у копилки — «✓ взнос выходит», у «Траты вне плана» — «потрачено N из доли» / «больше доли на N»; под бюджетом — **«В сбережения идёт N из M · Подробнее ›»** (прошлый месяц — «ушло»), «Подробнее» открывает «Сбережения меньше на …», если перерасход забрал часть, иначе — статистику месяца | выполнено на N% |
| Цвет лимита | зелёный — **в пределах лимита**; оранжевый — **больше лимита, но месяц укладывается в план**; красный — **план месяца превышен** | темп, норма |
| Индикатор заполнения | **прогресс**; бледная часть — другие дни, яркая — выбранный период; **отметка** — где были бы траты при ровном темпе | полоска, риска |
| Группа категорий со своим цветом | **раздел** («Разделы», «Без раздела») | тип, группа |
| Пункт плана переходит в следующий месяц с суммой | **повторять каждый месяц** (переключатель в шите суммы у лимита и разового платежа; в плане — синий значок с булавкой в углу значка строки) | закрепить / открепить |
| Пояснение значков строк плана | **«Что значат значки»** (ссылка под всеми разделами плана) → шит **«Значки плана»** | легенда |
| Убрать категорию мерчанта (новые операции приходят без неё, прошлые не меняются) | **открепить категорию** | не назначать автоматически |
| Категория, которую мерчант даёт новым операциям | **категория мерчанта**; бейдж «авто» | правило мерчанта, запомнена |
| Операция, которую ещё не открывали и не разобрали | **новая**; действие — «Отметить просмотренными» | непрочитанная, не просмотрена |
| Уведомления из приложения банка | **уведомления приложения TBC** | пуши |
| Последний баланс из SMS банка плюс операции после него | **баланс карты**; при нескольких банках — **«Балансы карт»** | остаток на карте |
| Откуда читаются операции (TBC, Bank of Georgia) | **банк** (Настройки → «Банки», фильтр «Банк»); банк **читается** / выключен; **разбор**: встроенный или шаблоны сообщений | источник, провайдер |
| Деньги со своей карты на свою карту или свой счёт в другом банке (накопительный тоже) | **«Между своими картами»** (системная категория в переводах): не трата и не доход | внутренний перевод, «Сбережения» (категории больше нет) |
| SMS банка, уже лежащие в телефоне | **импорт SMS из телефона** | загрузка, синхронизация |
| Как разбит список операций | **группировать**: «По дням», «По месяцам», «По мерчантам», «По категориям», «По типу», «По сумме» | сортировка |
| Фильтры списка | «Применено фильтров: N», **«Сбросить все»**; в листе фильтра — **«Снять выбор»** | — |
| Мерчант, у операций которого разные категории (на его странице — список карточек, как в «Сменить категорию»; несколько — кнопка «Добавить», мусорка справа («Удалить: …»; в перетаскивании её нет), под заголовком «Зажмите, чтобы сменить порядок.»; зажатие включает перетаскивание (иконка справа только тогда; карточка встаёт на место соседа и за список не выходит), «Готово» выключает его; «Сменить» у одной: зажатие другой оставляет текущую отмеченной, она первая; на странице операции — чипы: тап отмечает, одна сохраняется сразу, страница не закрывается, две и больше — «Разделить»; «Сменить» тоже сохраняет и не закрывает; у возврата те же чипы; порядок один и тот же в списке, в чипах и в уведомлении) | **разные категории** («Разные категории у «WOLT»», раздел списка «Разные категории») | смешанный |
| Первая категория в списке мерчанта (звёздочка её цвета слева, без кружка; у остальных — кружок). Новые операции получают её; уведомление всё равно приходит, и если категорию не выбрать — остаётся она | **основная категория** | главная, дефолтная |
| Две и больше категорий в одну | **объединить** | слить |
| Одна операция на несколько категорий (чек: продукты + хозтовары) | **разделить по категориям** (в листе «Сменить категорию»: «Несколько категорий можно выбрать зажатием.», «Готово» открывает лист; на странице операции мерчанта с разными категориями — два синих чипа и «Разделить»; «Отмена» снимает отметки в листе; «+ Ещё категория» — тот же список с уже отмеченными); операция **разделена**, у неё **части**; первая категория получает **остальное**; обратно — **«Убрать разделение»** | разбить, распределить |
| Операции удаляемой категории за этот месяц | **перенести** в одну категорию (одна операция — «Перенести в другую категорию»); **разложить по разным категориям**; уйти посередине — **«Прервать»** | раскидать |
| Часть бюджета, отложенная в сбережения в начале месяца (🔒) | **«Отложить сразу»**, в плане, итогах, истории и отчёте — **«🔒 Отложено сразу»** («заблокировано в начале месяца») | «Сразу» отдельно |
| Категория, на которую копят заранее (отпуск, страховка) | **копилка** (в плане — в разделе «Сбережения», в статистике — «Копилки»); каждый месяц — **взнос** (часть бюджета); траты из неё — **«из копилки»**, не хватило — **«Не хватило … — взяты из бюджета …»**; удалить — **«Удалить копилку»** (накопленное — в сбережения месяца) | цель, накопление, фонд |
| Подписка или регулярный платёж реже раза в месяц, на которые копят как на копилку | **«Откладывать каждый месяц?»** («Да, по N ₾ в месяц» / «Нет, весь платёж в марте»); в плане — строка **«Предстоящие подписки»** (у категории без подписок — «Предстоящие платежи») в разделе «Сбережения» (как копилка: кольцо, «копим: …», взнос «в месяц»), в её разделе — только списания; списание — **«из отложенного»**; выключить — **«Не откладывать на …?»** (отложенное — в сбережения месяца) | копилка подписки, резерв |
| Платёж раз в период (аренда, спорт, страховка, обеды) | **регулярный платёж**: вид **«Регулярный платёж»** в шите суммы плана — только план, с операциями не сверяется; как часто — «Каждый день» / «Каждую неделю» (чипы «пн» … «вс»; **«Сумма за раз»**, «9 раз в октябре — 180 ₾», «Повторяется каждый месяц, пока не задана дата окончания.», в строке плана «пн, чт · 9 × 20 ₾ · до 15 окт») / «Каждый месяц» … «Раз в год»: «Сумма платежа», **«Дата списания»** — реже раза в месяц (можно прошедшую: следующие — через период от неё, «Следующие — раз в год от этой даты; списание встанет в план своего месяца.»); у «Каждый месяц» даты нет — «Сумма стоит в плане каждый месяц.»; у всех и у лимита с «Повторять каждый месяц» — **«Дата окончания (необязательно)»** («Убрать»); выключается другим видом в шите суммы; в плане строка категории — в её разделе, со значком 🔁; выключить с отложенным — «Выключить регулярные платежи?» | повторяющийся платёж, абонемент, «это оплата?» |
| Мерчант категории, списания которого отслеживаются (Netflix, связь, страховка) | **подписка**: свитч **«Подписки»** на странице категории с операциями мерчантов (у «📺 Подписки» — сразу; «Включить подписки?» / «Выключить подписки?», тосты «Подписки включены» / «Подписки выключены»; под ним — подписки и **«Мерчанты без подписки»** («Сделать подпиской»)); шит — два вида: подписки месяца («Списания в октябре», «Без даты списания», внизу «Предстоящие подписки ›») и **«Предстоящие подписки»** («Копим» — на которые откладываем, «Без откладывания» — позже; внизу «Подписки октября ›»); делается из мерчанта категории («Сделать подпиской», «Задать дату»; из шита суммы плана — **«Выбрать мерчанта»**); «Изменить подписку ›», «Удалить подписку», **«Изменить в плане ›»**; как часто — «Каждую неделю» / «Каждый месяц» / «Раз в 3 месяца» / «Раз в полгода» / «Раз в год» / «Один раз» / «Другое…» (в строках — «каждый месяц», «раз в год», «один раз»); у разовой вместо «Следующее списание» — **«Дата списания»**; одна подписка перестаёт повторяться — «Один раз» или «Удалить подписку» | повторяющийся платёж, абонемент, «Разные мерчанты» |
| Деньги, снятые по подписке | **списание**: «Следующее списание», «Списания в октябре», «✓ списано 10 окт», «В этом году списано»; дата не задана — **«Без даты списания»**, «Задать дату» | автоплатёж, оплата подписки |
| Траты категорий без плана и без категории | **вне плана**; часть бюджета на них — **доля вне плана** | незапланированные, прочее |
| Разбор месяца с планом: что отложено, что улучшить | **отчёт** («Отчёт за сентябрь»; открывается после итогов месяца); у месяца без плана отчёта нет | итоги (это ответы, см. выше), сводка |
| Скрыть цифры на экране статистики (глазик) | **скрыть суммы** | приватный режим |
| В какой валюте показывать суммы | **валюта** (Настройки → «Валюта»); пересчёт по курсу НБГ | основная валюта |

## Правила
- Обращение на «вы» с маленькой буквы.
- Сумма — число и символ валюты после неё через неразрывный пробел: `1 400 ₾`, `12.50 $`.
- Диапазон дат — через « – »: `28 сен – 4 окт`.
- Пример суммы в подсказках: «например, 1500 или 12.50».
